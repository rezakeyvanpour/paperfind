# PaperFind | پژوهان

A Persian-language academic research discovery platform.

## Status
Frontend prototype in development. Search results currently use sample data.

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure
```text
paperfind/
├── index.html
├── README.md
├── .gitignore
└── src/
    ├── css/
    │   └── main.css
    └── js/
        └── app.js
```

## Getting Started
Open `index.html` in a modern browser to run the application locally.

## Scope
Current development focuses exclusively on the frontend. Backend services and live academic search are not yet implemented.
